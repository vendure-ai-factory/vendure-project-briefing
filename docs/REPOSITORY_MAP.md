# Repository Map

| Repository | Visibility | Purpose | Contractor path |
| --- | --- | --- | --- |
| `vendure-project-briefing` | Public | Sanitized project briefing, public acceptance overview, and runnable demo | Anonymous read, clone, fork, local changes, optional PR |
| `vendure-evaluation-input` | Private | Formal legacy source, fixtures, task documents, and acceptance inputs | Only the approved private access needed after contract |
| `pipeline-contract` | Private | Full pipeline interface, evidence schema, runtime constraints, and acceptance contract | Contracted delivery and maintainer review only |

The repositories are connected by explicit versions and case identifiers, not by exposing private Git history or hidden submodules. The public demo is a reviewed representative case and must not be treated as the private source.
