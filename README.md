The public test package is sanitized. Contractors may clone or fork the branch, run the demo, adapt their own pipeline in their own copy, and submit a fork URL, commit SHA, or pull request for review. A pull request is a submission surface only; it does not grant merge rights and does not mean the code will be merged.
